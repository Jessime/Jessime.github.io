Reasoning LLM:
A Bioinformatics Coding Interview

Here's the question I used to use at Invitae to interview bioinformatics engineering candidates, how it's solved by two reasoning LLMs, and a few conclusions.

The interview question

I have a FASTA file containing a collection of sequences. Each sequence has a name, and each is the same length. The task is to find sequences that are similar, then connect them in a graph.

It starts with a small question: how different are these two sequences? The Hamming distance counts the positions where they disagree.

You can assume that the FASTA file is well formatted and there is only one sequence line per header line.

A small piece of the problem

Here is one function to fill in. The inputs are simple; the interesting part is deciding what “similar” should mean.

Pythonsequence_similarity.py
def are_similar(seq1, seq2, threshold=3):
    """Return whether two sequences are similar."""
    distance = sum(
        a != b for a, b in zip(seq1, seq2)
    )
    return distance <= threshold

Make the assumptions visible

For equal-length inputs, a few examples make the behavior easy to inspect. Here the reference sequence is AGTCTGCT and the threshold is 3.

Once that relationship is defined, the next steps are to build the graph and find second-degree neighbors. That's where a short coding exercise opens into a conversation about structure, testing, and judgment.
